###Employee Salary Calculator
A desktop application built with C#, WinForms, and SQL Server for managing employees and salary records.
The system allows users to store employee information, create salary payments, calculate total salary based on worked days and daily wage, and manage payroll records through a clean desktop interface.

Overview
Employee Salary Calculator is a payroll management desktop application designed to simplify employee and salary administration.

The system provides two main modules:

Employee Management
Salary Management

Users can add employee records, manage employee details, create salary payments, calculate paid amounts automatically, and store all records in a SQL Server database.

Features
Employee Management

Salary Management :
